DW Simplified Header

A ServiceNow internship exploration for Dynamic Window focused on consolidating six key actions into one clearer header, then supporting discoverability with lightweight onboarding tooltips.

Role

Product Designer (Intern)

Time

2026

Approach

Requirement decomposition
Interaction direction exploration
High-fidelity prototyping (Figma Make)
Usability validation

Output

Dynamic Window unified header solution
Lightweight guidance content and teachable interactions

Reflection

Optimizing high-frequency workflows should balance onboarding clarity and in-task efficiency without sacrificing either.

Result

Improved primary-action discoverability and cross-state consistency.

Dynamic Window is an AI workspace where users interact with AI while staying in their current workflow. This project focused on simplifying the header so six core actions could be found faster and understood more consistently across all states.

Rather than redesigning the entire workspace, the challenge was to make a small but high-frequency surface feel more obvious, more teachable, and less visually fragmented.

Discuss this project ↗

A clearer header without leaving the workflow.

Because DW lives beside active product work, even a small control surface has to feel intuitive immediately. The header mattered because it shaped how discoverable the whole assistant felt.

Three directions for a clearer header.

Katherine explored three directions first, and I collaborated on version three using Figma Make to create a higher-fidelity interactive prototype ready for UX validation.

Research

Validation focused on discoverability, comprehension, and consistency.

UX research tested whether users could discover the six actions, understand the new consolidated header, and navigate consistently across all Dynamic Window states.

Finding 1

Discoverability remained the core metric.

The simplified header had to make actions easier to spot immediately, especially for first-time users.

Finding 2

Consolidation needed explanation.

Onboarding cues helped users understand why the header changed and what each control now represented.

Finding 3

Consistency across states mattered most.

Users built confidence faster when the same header logic held up across every DW layout variation.

Final Design

A clearer header with lightweight guidance.

One consolidated header and contextual tooltips made six actions easier to find and understand.

Tooltips

Lightweight, contextual guidance.

Tooltips explained the new structure without interrupting the workflow.

Refinement

Research guided final decisions.

Testing confirmed the grouping and behavior across Dynamic Window states.

Reflection

This project reinforced how AI, research, and collaboration can sharpen interaction decisions.

The final takeaways were not only about header simplification, but also about using AI-assisted making, rapid prototyping, and user feedback together to make a smaller workflow decision much stronger.

Learning 1

Designing with AI can accelerate exploration.

Figma Make helped the team move from concept to interactive prototype faster, making discussion and testing more concrete.

Learning 2

Research validates interaction tradeoffs.

User testing clarified whether simplification actually improved comprehension instead of merely reducing visual noise.

Learning 3

Collaboration strengthens refinement.

Working across design directions and prototype iterations made the final header feel more intentional and more defensible.
